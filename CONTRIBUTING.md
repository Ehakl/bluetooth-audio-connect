# Contributing

Keep device selection exact and unambiguous. Do not add radio resets, driver/service toggling, pairing removal or hidden downloads as fallbacks. Keep status and discovery read-only. Add tests for selection/CLI changes and document hardware results separately from offline tests.

Report Windows version, device model, command and error code. Remove personal names and device IDs from shared logs. Never commit local settings, logs or binaries. Do not suggest antivirus bypasses; investigate and resolve detections before distributing releases.
